# 拟人化逐句发送 (human_like_engine)

把一段长回复按标点切成几句，**一条一条**发出去，并模拟真人打字节奏。

## 行为

1. **只按标点切分**：`。！？~…` 断句；单句过长时才在逗号处补切；绝不做字数硬切。
2. **短回复整条发**：两句话以内不拆分。
3. **碎片合并**：`嗯嗯，` 这类过短的碎片并入下一句，避免气泡太碎。
4. **逐条发送**：`event.send()` 循环发送，不会拼成一大段。
5. **打字节奏**：开口前有阅读缓冲；句间停顿 = 随机区间 + 下一句字数 × 系数。
6. **正在输入**：停顿期间尝试调用 OneBot `set_input_status`，接口不支持时静默跳过。
7. **插话不吞句子**：用户中途发言时剩余句子照常发完，只是被加速（默认 3 倍）。
8. **去掉句号**：正常聊天不发送句末的 `。`（`？！～` 保留）。
9. **异常静默**：发送失败只写日志，不向用户抛错误。

## 安装

放进 `data/plugins/`，重启 AstrBot。适用于 AstrBot >= 4.0.0。

## 配置

见 `_conf_schema.json`，所有参数都能在插件配置页调整。
